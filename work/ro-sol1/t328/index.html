Nano-Phys has a visual-quality cost on this benchmark.

Author-reported · provisional

dk2 scored the existing held-out pendulum clips. Compared with plain Nano, Nano-Phys lost 0.057 DOVER on the matched grid. The motion-fidelity score needs a prominent qualification.

A motion-fidelity score of 1.000 is degenerate here

Source MF: plain 0.238 → Nano-Phys 1.000. Every real reference and every Nano-Phys clip has binary DD = 0; plain has 7/18 clips flagged dynamic. Under ddof=0 and the disclosed 0/0 → 0 MC convention, even a static output earns MF = 1 against this zero-DD reference.

This score cannot certify correct pendulum motion. MF implements the published Cosmos 3 formula using an approximate DD scorer. It is not an NVIDIA-identical evaluation.

Continuous flow proxy: real 1.94, plain 4.83, Nano-Phys 0.44. Nano-Phys undershoots real flow. The proxy does not identify whether bob motion, camera motion or background motion was lost.

What this evidence covers

  • Existing clips, new scores: the author re-scored 42 task-276 clips on an RTX 4060 using the unchanged shared scorer, with 3 DOVER repetitions. Their source records MP4 hashes and reports 42/42 sidecars identical to task 276.
  • Supplied dynamics: Nano-Phys used a simulated proxy, sigma 0.90, and a period derived from later real-video frames. The earlier 12/18 period-transfer demo remains conditional on that supplied period; it is not a first-frame-only physics solution.
  • Small, shared-rig reference: six 93-frame real windows have nominal 25 fps metadata versus generated 24 fps. For MF, the author re-encoded the real references at 24 fps, reporting unchanged frame sequence. Retiming changes playback time; it does not establish the original camera clock or an independently matched physical duration.
  • Implementation scope: shared DD uses torchvision RAFT/PyAV and differs from original VBench. Nvidia's original report used 5-second clips and roughly 100 real references per FPS band. This grid is shorter and narrower.
  • Wrong-period comparison: x17 minus Nano-Phys is −0.00090 DOVER when restricted to their six matched seed-1 pairs. This is a descriptive comparison, not equivalence or identification of the cause of the quality drop.
  • Still untested: plausibility judge, robot prediction, new prompts/rigs, and the cause of the DOVER drop.
Suggested wording for a human to apply
“Nano-Phys transfers a supplied pendulum period, with a visual-quality cost. On six held-out input images × three seeds, the author reports a 0.057 DOVER drop versus plain Nano. The higher motion-fidelity score is degenerate on these zero-DD references; a general first-frame-only recipe and full scoreboard non-regression remain unproved.”
