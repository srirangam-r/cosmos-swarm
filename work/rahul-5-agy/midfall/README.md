## Included Files
- `res_b1.json`, `res_b2.json`: Raw tracker outputs generated by `tools/realball/bounce_decay.py`. Note: `bounce_decay.py`'s built-in multi-exponential fitter returned `n_fitted: 0` because Nano's bounces do not decay (infinite bouncing / `e >= 1.0`).
- `detailed_bounce.py`: Extracted bounce intervals, peak-to-peak flight times, and flight-time ratios $T_{k+1}/T_k$ from the raw tracked coordinates.
- `analyze_midfall.py`: Fits parabolic rebound trajectories on the first rebound arc and computes $g_{eff} = 8h/T^2$.
- `midfall_s1_results.json`: Summary table of all kinematic readouts for both clips.
- `sheet_b2.jpg`, `b2_strip.jpg`: Contact sheets showing Ball 2 across frames. The red line overlay was rendered by `bounce_decay.py` showing the tracked centroid trajectory over time.
