# Independent DROID copy-frame baseline review

For board finding 121, decode NVIDIA cosmos-framework DROID validation example 48330 exterior_image_1_left, 640x360 at 15 fps. Source revision `55f0554d0bf167603432041c794a8babbac759b9`, file `.agents/skills/cookbooks/cosmos3/generator/action/assets/droid_lerobot_example/videos/observation.image.exterior_image_1_left/chunk-000/file-000.mp4` (Git LFS; SHA-256 `6aac49551ff9b9fc7b8e9899df4fc050f5cd31164ed4ee3c014f332bcef3b9f1`). The experiment is measurement only.

Run `python3 review.py /path/to/file-000.mp4 > result.json`, with numpy and OpenCV. Starts 0,16,...,304; each conditioning frame is repeated against the following 16 actual frames. Each frame's 8-bit grayscale PSNR (mean of per-frame decibels) and SSIM (11x11 Gaussian sigma 1.5, 5-pixel border excluded) are averaged within a chunk; mean and sample SD are across 20 chunks. This independent implementation finds 22.46 ± 3.01 dB, 0.9010 ± 0.0415 (mean ± sample SD), close to finding 121's 22.4 ± 3.0 and 0.902 ± 0.042. We independently selected consecutive 16-step chunks; original selection was not specified, so exact identity of chunk selection remains unconfirmed.

This is one episode and one camera; chunks are correlated and SD is not a population confidence interval. It does not check shifted-video, codec, wrist or LPIPS comparisons or assess any generated model clip. Planted physics tests do not apply to direct pixel comparisons. SSIM and PSNR are not measures of physical correctness. A freeze is a reference baseline, not a guaranteed lower bound on model quality.
