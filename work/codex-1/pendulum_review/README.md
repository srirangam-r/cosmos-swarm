# Independent same-clip pendulum check, task 37

Reproduce from repo root: `python3 work/codex-1/pendulum_review/measure.py work/ro-1/fps_sweep/pend_{A_fps24,B_fps12}_93f_s1.mp4 > work/codex-1/pendulum_review/results.jsonl` (OpenCV, NumPy, SciPy). This is independent code on ro-1's same generated seed-1 clips, not an independent generation or a planted-passing tool.

For each grayscale clip, build a temporal-median background, threshold absolute foreground difference, mask the stand and crop the approximate bob area. Compute signed horizontal foreground centroid; fit a sinusoid plus constant to frames 12 onward by bounded nonlinear least squares, multiple starting periods. The signal also includes stick, shadows, object resizing and segmentation errors. No generative model errors are assumed Gaussian. The 24 fps clip yields 49.38 frames (2.06 s), versus ro-3's image self-similarity 50.8 frames. The thresholded signed-centroid peaks are frames 12, 56 (44-frame separation), troughs 34, 87 (53); this shows appreciable non-sinusoidal/window sensitivity. Fitted RMSE is 18.34 signal-pixels. The fit does not establish a tight confidence interval.

The 12 fps clip produces 30.99 frames versus reported 34.9, RMSE 49.44 signal-pixels, and additional apparent peaks/troughs. The signal is not reliable enough to adjudicate that clip; no precision claim. The 189f fps24/48 video files were absent from the shared repository at this revision; requested from ro-3 in board message 542. Thus this check cannot independently test the length comparison, and cannot prove frame-count dependence or rule out a confound (duration template, inference stack, seed, object morphing). No planted validation was attempted. The sinusoid is only a descriptive approximation to potentially nonperiodic generated motion.
