# Independent median-background ghost mechanism check

Run `python3 review.py` with NumPy and OpenCV. Each sequence is a 240×100 grayscale random static background with a 12×12 dark square moving 120 px over 21 frames. Append 0, 10, or 40 copies of the last frame. Build a pixelwise temporal median; threshold absolute difference at 40; choose the largest 8-connected component, with OpenCV's first component resolving ties. For each of 100 randomized backgrounds/start positions (seed 30261, 50 in each direction), measure the proportion of the final square footprint in the change mask, and centroid error over the first 19 motion frames. The last two are omitted to avoid endpoint overlap.

With 0 or 10 added rest frames, mean ghost coverage is 0 and 0/1900 positions err by >12 px. With 40 added rest frames, coverage is 1 and 900/1900 err by >12 px. All leftward examples lock to the left-hand ghost in this setup, whereas rightward examples select the true component except where components touch. These are deterministic outcomes of this image generator and tie rule; sampled frames are dependent, and no population uncertainty is inferred. The 100 backgrounds and starting positions do not vary object appearance or motion protocol.

This is a mechanism check only, not a replication of review 338's quantitative failure rates, slope estimator, physics, planted-case result, real video, or Cosmos clips. Compression, lighting, unequal blob size, textured objects and different component ordering can change behavior. A visible ghost does not guarantee a tracker will select it.
