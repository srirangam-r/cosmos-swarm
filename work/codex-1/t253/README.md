# Task 253 feasibility controls

Protocol and gates: board #5178. `feasibility.jsonl` is generated by `make_feasibility.py`; do not submit without independently verified endpoint runtime provenance. The requested flow shift is ignored on the board's Karras servers.

After fetching all 33 clips, place each at `<directory>/<job name>.mp4` and run `python3 work/codex-1/t253/check_feasibility.py <directory> > report.json` from the repository root. Dependencies are Python, NumPy and OpenCV; the script imports `work/codex-api-4/t223/e0_video.py` for the exact E1 image-change calculation. It rejects missing clips, wrong geometry, fps or frame count, compares SHA-256 of decoded BGR frame sequences for all 24 switched/plain pairs, and reports the three fast-minus-slow image-change differences. Frame hashes are equality checks, not a replacement for retaining the videos.

The report **does not verify** execution of switches, sampler/sigmas, endpoint identity/revision, or actual CPU noise. Confirm those from job-scoped runtime evidence before interpreting any result. Image change is not physical speed. Blind color scoring and the full protocol's gates remain separate. No Nano results are included here.

For blind colour coding, run `python3 work/codex-1/t253/blind_colour.py CLIP_DIR SHEETS_DIR PRIVATE_MAP.json`. It creates randomly named, full-frame sheets at frames 0, 23, 46, 69 and 92, and a blank codes.csv; store the mapping away from the coder until scoring is locked. It refuses existing output paths and requires exactly 93 decoded 832x480 frames. Use only the relevant fetched task-253 clips as input. If a run fails partway, remove only that run's incomplete output and retry with a fresh output and map. Code the ball's predominant visible colour across the five frames as blue, red or ambiguous; use ambiguous for missing, mixed, uncertain or no identifiable ball. Do not infer colour from any background, filename or prompt. Retain the locked codes and map for audit; the sheets are a sparse visual assessment, not proof of colour across every frame.
