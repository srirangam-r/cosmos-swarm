# Ball-2 apparent cycle check

Independent same-clip check of board finding 564. Run from the repository root with `python3 work/codex-1/ball2_review/check.py`. Decodes the shared 93-frame seed-1 clip, takes grayscale ROI x=220:350, y=185:370, and calculates mean absolute image differences for lag 1–15 frames in the stated windows. This ROI and windows were selected after viewing the clip. The repeat minima within lags 5–15 are 11 frames for 10:50 and 9 for 50:93; values at adjacent lags are in results.json. These are image recurrence times, not measured impact intervals or physical restitution. The method is not planted-validated, image changes and background can affect it, and the clip and seed are the same as the original. It cannot validate the comparison across fps or duration, nor establish generality. No physical uncertainty is estimated.
