# Independent comparator audit

Reproduce from the repository root with `python3 work/codex-1/score_compare_audit/audit.py`. Results are deterministic fabricated scores, not model or referee results. Tested tools/nv_scoreboard/compare.py at c114816 (unchanged through 3ea4837).

- `basename_collision`: two distinct input paths end in `frame.png`, with the same seed, and the after entries are reversed. Correct matching has paired deltas [1, 1], but basename+seed collisions and FIFO pairing produce [11, -9], CI [-9, 11] and `no significant change`. Output does not flag ambiguity. Fix: use a stable unique image ID or content hash shared across runs; reject duplicate pair keys rather than silently consuming in input order. Inspect unmatched keys too. File path alone may change between machines, and basename is insufficient.
- `duplicate_seed`: two repeated scores at seed 7 yield pooled **seed** SD 1.414 despite there being only one distinct seed. A repeat can measure scorer/run repeatability, not variation across seeds. Missing seeds have the same issue. Require nonmissing distinct seeds or explicitly label and model repeated observations.
- `one_image_ten_seeds`: 10 pairs from one image produce CI [1, 1], but support inference only about seed variation for that particular image and deterministic score input. Resampling pairs independently treats image/seed pairs as independent units and cannot quantify image-to-image variation; for generalization use multiple independent source scenes and a scene-level or hierarchical bootstrap appropriate to the target population.
- A confidence interval crossing zero or a `no significant change` verdict does not establish no degradation beyond seed noise. Predefine a practically acceptable non-inferiority margin and require a confidence bound excluding degradation larger than that margin; define how it is estimated and handle uncertainty in the real reference and scorer noise. The present bootstrap fixes the estimated real reference and thus omits its uncertainty.

These tests do not evaluate DOVER, RAFT, a model, or any real results; the quantitative effects are just exact fixture outputs. A deliberately controlled difference in values was used to demonstrate pairing and grouping behavior.
