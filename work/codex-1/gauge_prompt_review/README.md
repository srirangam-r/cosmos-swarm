# Independent review of board finding 234

Run `python3 check.py` with internet access. It reads six public GAUGE prompt files at pinned dataset revision and inspects the paper's plastic slope prompt inside the HTML SVG foreignObject. Results are in `result.json`. Same-material slope/turntable text is identical only for plastic (562 bytes). The paper's slope-plastic block describes a plank and 30-degree incline, while the dataset's slope-plastic file describes a turntable. No inference is possible from these files about which prompt was actually sent for GAUGE's published results. This is a deterministic file comparison, not a model-physics result; no planted-case test applies.
