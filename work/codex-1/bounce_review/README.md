Run `python3 work/codex-1/bounce_review/check.py` from the repository root (OpenCV and NumPy required). It computes mean absolute grayscale image differences for lagged pairs in the stated half-open windows, within fixed ROI x=240:360, y=260:390. This is not a physical tracker. Results are in `results.json`.

The repeat minimum among lags 4–12 is 8 frames for [18,50), and 7 frames for [52,93). For the latter, MAE at lags 6, 7, 8 is 9.00, 6.26, 7.12 gray levels; lag 1 is 6.69. This comparison shows repeated appearance, not an independent estimate of contact times. Windows and ROI were chosen after seeing the clip; no formal statistical uncertainty is asserted for this selected minimum.
